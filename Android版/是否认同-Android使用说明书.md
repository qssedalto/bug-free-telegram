# 《是否认同》Android 版使用说明书

## 1. 应用信息

- 应用名称：是否认同
- 当前版本：1.1.0（versionCode 2）
- Android 包名：`com.tglab.shifourentong`
- 厂商：TGLab
- 最低系统版本：Android 6.0（API 23）
- 目标系统版本：Android 14（API 34）
- 默认标题：`对于甲，有一些问题`
- 默认居中问题：`是否认同甲是大傻福？`

Android 版按照当前 Windows 版的金额算法、剧情内容和视觉方向重新实现，采用原生 Android 界面，能够适配手机和平板。应用数据保存在本机应用专用目录中，不会写入公共文件夹。

## 2. 安装方法

1. 将 `ShiFouRenTong-Android-v1.1.0.apk` 复制到 Android 设备。
2. 在设备文件管理器中点按 APK。
3. 如果系统阻止安装，请只为当前文件管理器临时允许“安装未知应用”。
4. 确认应用名称为“是否认同”，然后完成安装。
5. 安装成功后，可关闭刚才临时授予的“安装未知应用”权限。

升级时直接安装由同一签名密钥生成的新版本即可保留本地配置和剧情记录。请勿丢失 `Signing/tglab-shifourentong.keystore`，否则后续版本无法直接覆盖当前版本。

## 3. 主界面

主界面包含标题、状态栏、工具按钮、居中问题、三个剧情选择、当前金额、近七日趋势、剧情进度、最近选择、成就和每日台词。

三个主要选项分别进入不同剧情分支：

- 认同：展示多阶段剧情、当前人民币金额、中文金额及联网 BTC 换算。
- 非常认同：进入更强烈但随机变化的肯定剧情。
- 不认同：进入带倒计时的警告与随机逃离结果。

剧情文案从大规模组合池中按分支随机生成。主界面的三个彩色进度会随选择次数更新，重新开始剧情后同步归零。

## 4. 金额与计算规则

- 默认起始日期：2023 年 6 月 19 日。
- 默认初始金额：1008 元。
- 默认按每日 5% 复合增长计算。
- 内部使用任意精度整数计算，显示最多保留 99 位，避免固定整数类型溢出。
- 阿拉伯数字金额从右向左每三位加入英文逗号，并在前面显示 `￥`。
- 中文金额使用日常中文数字表达，不添加“人民币大写”或“整”。

“金额”按钮可直接显示当前欠款；窗口会根据内容换行，避免位数增加后裁切。

## 5. 数据面板

数据面板可查看：

- 昨日、七日前和三十日前金额对比。
- 明日、一周后和一年后的金额预测。
- 当前运行天数及公式参数。
- 近七日与近三十日增长趋势。
- 美元、欧元、日元和港币换算。
- 黄金重量换算，单位为吨。
- BTC 换算，结果精确到小数点后五位。
- 本地选择记录、连续签到、里程碑及成就。
- 一键重新开始剧情并清零剧情进度。

汇率、黄金价格与 BTC 价格需要网络。应用会根据公网 IP 自动选择行情路径：检测到中国大陆 IP 时，外汇优先使用中国银行牌价、黄金优先使用上海黄金交易所 Au99.99、BTC 优先使用 MEXC BTC/USDT 并结合中国银行美元折算价；其他地区优先使用原有国际行情源。任一首选来源失败时会自动尝试另一组来源。网络完全不可用时，应用会显示明确的失败信息，金额主功能和离线剧情仍可正常使用。

## 6. 设置

设置页支持修改：

- 起始日期与初始金额。
- 标题、问题、人物名称和自定义剧情文本。
- 浅色、深色和纯黑主题。
- 强调色、字号缩放和高对比度模式。
- 减少动画、音效和全屏演示模式。
- 中文或英文界面。
- 中性措辞或虚构角色模式。

保存设置后主界面会立即重建并采用新配置。配置与历史记录均保存在当前 Android 应用的内部数据目录中。

## 7. 隐藏内容

标题、每日台词、金额入口和警告倒计时中包含隐藏交互。不同分支、连续点击及选择次数可能触发不同彩蛋；彩蛋内容不会影响金额算法。

## 8. 权限与隐私

应用只声明互联网权限，用于判断公网 IP 所属国家或地区，以及取得实时 BTC、法定货币及黄金换算数据。IP 判断端点会像普通网站一样看到请求来源的公网 IP；应用只读取两位国家或地区代码，不保存完整 IP，也不会上传剧情选择、人物名称、金额设置或历史文件。应用没有通讯录、短信、麦克风、摄像头、精确位置或存储读取权限，也不包含系统托盘功能。

## 9. 完整性校验

发布目录中的 `SHA256SUMS` 保存 APK 的 SHA-256。Windows PowerShell 可使用下列命令检查：

```powershell
Get-FileHash -Algorithm SHA256 .\ShiFouRenTong-Android-v1.1.0.apk
```

输出应与 `SHA256SUMS` 中的值一致。

## 10. 开发构建

构建要求：.NET 8 SDK、`.NET for Android` 工作负载、Android SDK 34、JDK 17，以及项目自带的签名密钥。

设置签名口令环境变量后运行：

```powershell
$env:SFR_ANDROID_SIGNING_PASSWORD = '<本地签名口令>'
.\Build-Android.ps1
```

如未配置 `JAVA_HOME`，可以使用 `-JavaSdkDirectory` 指定 JDK 17；Android SDK 不在工作区 `.android-sdk` 时，可使用 `-AndroidSdkDirectory` 指定。

构建成功后，正式 APK 和 SHA-256 文件会写入 `Android版/发布`。
