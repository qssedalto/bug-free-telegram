是否认同？

一个诞生于 2022 年的 SwiftUI 小作品。

关于

某天突发奇想写出来的恶搞 App。

功能很简单：

* 认同
* 非常认同
* 不认同

然后会触发各种意想不到（其实也挺意料之中）的剧情。

技术栈

* SwiftUI
* UserDefaults
* 一点点数学
* 一点点恶趣味

特性

* 会记录打开次数
* 会自动计算一个神秘金额
* 会出现 SCP 级别威胁
* 开发者会选择性原谅你

状态

本项目已停止更新。

保留此仓库仅作为个人代码存档与纪念。

历史备注

三年后的我重新打开这个仓库时：

* 代码已经看起来有点古老
* 命名已经开始暴露时代特色
* 逻辑依然非常离谱

但这大概就是当时最真实的自己。
