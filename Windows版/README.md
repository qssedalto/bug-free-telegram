# 是否认同（Windows 版）

这是 SwiftUI 示例的 Windows Forms 等价移植。最新版已经扩展为带数据看板、剧情和个性化设置的桌面应用。

## 金额与数据

- 以 2023-06-19 为 `n = 7` 的固定起始日，按照本地自然日直接计算；
- 可在设置中修改起始日期和初始金额；
- 使用 `BigInteger` 进行金额计算，不依赖浮点数或固定宽度整数，避免数据溢出；
- 金额最多显示 99 位，超过后固定为 99 个 `9`，并标明已达到上限；
- 同时显示带 `￥` 的阿拉伯数字金额和普通中文金额；
- 数据看板提供增长折线图、昨日/七日前/三十日前对比，以及明日/一周后/一年后预测；
- 显示当前运行天数、公式参数、每日金额快照和本地选择记录；
- 在线换算 BTC、美元、欧元、日元、港币和黄金重量；BTC 显示到小数点后五位；
- 弹窗中可一键复制人民币与 BTC 数值；用户要求删除的行情来源和时间行不再显示；
- 离线或行情服务不可用时显示提示，不影响人民币欠款金额；
- 本地数据保存在 `%LOCALAPPDATA%\TGLab\是否认同` 的 JSON 文件中，与 Program Files 中的程序文件完全分离。

## 外观与窗口

- 主界面采用响应式“剧情控制台”：宽屏显示剧情双栏，窄屏自动堆叠并滚动；
- 首页包含今日档案、运行天数、金额位数、签到、三路线探索进度、最近选择、成就陈列架和七日迷你趋势；
- 三个剧情入口升级为带路线说明、探索状态、彩色边框和悬停反馈的圆角卡片；
- 顶部提供本地保存、行情与主题状态胶囊，底部提供每日台词及快捷键提示；
- 浅色、深色、纯黑主题，自定义强调色、字号、高对比度和减少动画；
- iPad 风格圆角弹窗、淡入、按钮缩放回弹、金额滚动和警告页呼吸效果；
- 全屏演示（`F11`）、窗口尺寸/位置和多显示器位置记忆；
- 始终置顶的迷你金额窗口和可关闭音效。

## 剧情与个性化

- 组合式文案引擎提供至少 1,000 种认同剧情、1,000 种非常认同剧情、2,000 种警告/逃离剧情和 1,000 种独立彩蛋文字；
- 文案由主题、现场变化和结尾动态组合，按钮仍与对应剧情主题绑定；
- 弹窗会根据最长文案、换行高度、字号缩放及当前显示器空间智能调整宽高；
- 自定义标题、问题、人物和剧情文本；中英文与中性/虚构角色模式；
- 二十多条每日台词，以及标题点击阶梯、按钮顺序密码、分支累计、倒计时点击、迷你窗口、每日台词双击、纪念日期、F12 隐藏终端和低概率随机彩蛋；
- 连续签到、分支/彩蛋成就、金额里程碑和历史选择记录；
- 支持剧情重新开始。

## 安装、运行与验证

- Per-Monitor V2 DPI 适配和响应式最小窗口约束；
- 主程序以普通用户权限运行；只有标准安装和卸载过程请求管理员权限。

面向用户的正式交付文件是 `Installer\Output\Setup.exe`。它默认安装到 `C:\Program Files\TGLab\是否认同`，安装位置页面始终显示并允许用户通过“浏览…”修改目录。

安装包不携带 .NET 运行时。Setup 会自动检测 64 位 Microsoft .NET 8 Desktop Runtime：已经安装时直接继续；缺失时征得用户同意，由安装器从微软官方地址下载并静默安装，不打开浏览器，也不要求手工下载。Inno Setup 只用于开发电脑编译，目标用户电脑不需要安装 Inno Setup。

安装器创建开始菜单快捷方式，桌面快捷方式由用户选择；卸载时可以保留配置、删除配置或取消卸载。发布者和厂商为 TGLab，应用内版权信息为“天国智造”。

运行内置边界测试：

```powershell
.\Installer\artifacts\publish\是否认同.exe --self-test
```

重新构建标准 Setup：

```powershell
.\Installer\Build-Setup.ps1
```

安装脚本、构建脚本、测试说明和 SHA-256 位于 `Installer` 目录。
