## 1. 软件简介

《是否认同》是一款将每日增长的超大金额、随机剧情、选择记录、成就系统和实时行情换算组合在一起的 Windows 桌面应用。

软件的主要用途包括：

- 按起始日期和初始金额计算每日欠款；
- 用阿拉伯数字和中文数字同时显示金额；
- 把金额限制在安全的 99 位显示上限内；
- 查看昨日、七日前、三十日前以及未来日期的金额；
- 查看最近 30 天的欠款增长折线图；
- 按需换算 BTC、美元、欧元、日元、港币和黄金重量；
- 通过“认同”“非常认同”“不认同”进入不同的随机剧情；
- 保存选择历史、每日快照、连续签到和成就；
- 使用浅色、深色、纯黑、高对比度和自定义强调色；
- 使用全屏演示和始终置顶的迷你金额窗口。

首次生成配置时，默认主界面文案为：

- 左上角标题：`对于甲，有一些问题`
- 中间问题：`是否认同甲是大傻福？`

如果电脑中已经存在旧版配置，升级安装会保留原来的标题和问题。这是为了避免覆盖用户自己修改过的内容；可在“设置”中手动改为新文案。

> 提示：如果不希望显示带评价性质的人物文案，可在“设置”中启用“中性/虚构角色模式”。启用后主问题和人物称呼会改为中性描述。

## 2. 系统要求

### 2.1 必需条件

- 64 位 Windows 10 或更高版本；
- x64 处理器或兼容的 64 位 Windows 环境；
- Microsoft .NET 8 Desktop Runtime（64 位）；
- 安装过程需要管理员权限；
- 主程序日常运行不需要管理员权限。

### 2.2 可选条件

- 互联网连接：用于 BTC、外币和黄金行情；
- 声音输出设备：用于剧情提示音；
- 高 DPI 或多显示器环境：程序支持 Per-Monitor V2 DPI，并会记住窗口所在显示器。

没有网络时，人民币欠款计算、剧情、历史、主题、迷你窗口和本地数据功能仍可正常使用。

## 3. 安装软件

### 3.1 标准安装步骤

1. 找到发布的 `Setup.exe`。
2. 双击运行。
3. Windows 会显示一次 UAC 管理员权限确认。
4. 核对发布者和程序名称后，选择“是”。
5. 进入中文安装向导。
6. 在“选择目标位置”页面确认安装目录。
7. 如需改到其他磁盘，点击“浏览…”并选择目录。
8. 在附加任务页面决定是否创建桌面快捷方式。
9. 点击“安装”。
10. 安装完成后，可选择立即运行《是否认同》。

默认安装目录为：

```text
C:\Program Files\TGLab\是否认同
```

安装位置页面始终显示。用户可以改为例如：

```text
D:\Program Files\TGLab\是否认同
```

也支持包含中文和空格的目录。

### 3.2 .NET 8 运行时检测

安装包不内置 .NET 运行时，以减小安装包体积。

启动 Setup 后会自动检测 64 位 `Microsoft.WindowsDesktop.App 8.x`：

- 已安装：不显示下载询问，直接进入安装向导；
- 未安装：询问是否从微软官方下载；
- 选择同意：安装器内部自动下载并静默安装，不会打开浏览器；
- 选择拒绝：取消主程序安装；
- 下载失败或运行时 UAC 被取消：终止安装并提示原因。

目标电脑不需要安装 Inno Setup。Inno Setup 只用于开发阶段生成标准 `Setup.exe`。

### 3.3 快捷方式

安装完成后：

- 开始菜单会创建《是否认同》快捷方式；
- 桌面快捷方式是可选项；
- 程序会登记到 Windows“设置 → 应用 → 已安装的应用”。

## 4. 首次启动

首次启动时，程序会自动执行以下操作：

1. 读取或创建本地设置；
2. 按本机当前日期计算欠款；
3. 写入当天金额快照；
4. 初始化或更新连续签到；
5. 检查金额位数和签到里程碑；
6. 恢复上次窗口大小、位置、显示器和最大化状态；
7. 根据“系统主题”或用户指定主题绘制界面。

首次启动不会主动联网。只有进入需要行情的页面时才会访问行情服务。

### 4.1 连续签到规则

- 第一次启动：连续签到记为 1 天；
- 与上次启动日期相差 1 天：签到天数加 1；
- 中断超过 1 天：重新从 1 天开始；
- 同一天重复打开：不会反复增加；
- 连续达到 7 天：解锁“连续七日”成就。

## 5. 主界面详解

主界面由顶部工具区、中间内容区和底部提示区组成。

### 5.1 顶部左侧：标题

默认显示：

```text
对于甲，有一些问题
```

标题可在“设置 → 窗口标题”中修改，最长保存 80 个字符。

标题本身可以点击，并包含分阶段彩蛋。正常使用不会因为点击标题而修改金额或设置。

### 5.2 顶部中间：状态胶囊

宽窗口下会显示：

| 状态 | 含义 |
|---|---|
| `● 已保存` | 当前设置和历史使用本地文件保存 |
| `行情按需` | 行情不会在后台持续刷新，只在需要时请求 |
| `系统主题` / `浅色` / `深色` / `纯黑` | 当前主题模式 |

窗口较窄时，状态胶囊会自动隐藏，为标题和工具按钮腾出空间。

### 5.3 顶部右侧：工具按钮

| 按钮 | 作用 |
|---|---|
| 直接展示金额 | 打开始终置顶的迷你金额窗口 |
| 数据 | 打开数据面板 |
| 设置 | 打开设置页面 |

### 5.4 今日问题区域

默认问题为：

```text
是否认同甲是大傻福？
```

问题可在“设置 → 问题文字”中修改，最长保存 160 个字符。问题区域会按可用空间自动缩小字号，尽量避免裁切。

### 5.5 三条剧情路线

主界面左侧有三张彩色路线卡片：

| 颜色 | 路线 | 按钮 | 主要内容 |
|---|---|---|---|
| 蓝色 | 档案调查路线 | 认同 | 金额档案、BTC 换算、多阶段揭示 |
| 绿色 | 共振与同盟路线 | 非常认同 | 多段随机文字、观点共振剧情 |
| 红色 | 警报与逃离路线 | 不认同 | 倒计时、红色警告、随机逃离结果 |

整张路线卡片和右侧按钮均可点击。鼠标经过时边框会加粗并显示路线颜色。

### 5.6 近七日增长卡片

路线下方显示最近七日的迷你趋势图：

- 左端为七日前；
- 右端为今天；
- 紫色或自定义强调色曲线表示增长趋势；
- 点击卡片任意位置可打开完整数据面板。

由于金额可能达到几十位，趋势图采用适合超大数字的比例处理；完整 30 日图明确标注为对数刻度。

### 5.7 右侧信息栏

宽屏时右侧显示四个区域：

1. **今日档案**：当前日期、运行第几天、连续签到天数；
2. **本次路线进度**：三条路线的历史探索量；
3. **最近选择**：最近一次选择时间、分支和结果摘要；
4. **成就陈列架**：最近解锁的成就和成就总数。

点击“最近选择”或“成就陈列架”可打开数据面板的历史内容。

### 5.8 底部区域

底部左侧显示每日台词。台词按一年中的日期轮换，双击台词可能打开彩蛋。

底部右侧显示快捷键提示：

- `F11`：进入或退出全屏演示；
- `F12`：打开隐藏终端彩蛋；
- 双击台词：查看台词背面。

### 5.9 窄屏与滚动

当主界面宽度不足时：

- 状态胶囊隐藏；
- 左右双栏变成上下排列；
- 剧情区和信息区保持最低内容高度；
- 主内容区出现滚动条；
- 组件不会为了塞进窗口而无限压扁。

最低主窗口尺寸约为 `920 × 700`。如果提高了字号缩放，建议使用最大化或全屏模式。

## 6. 欠款金额规则

### 6.1 默认时间锚点

默认配置为：

| 项目 | 默认值 |
|---|---|
| 起始日期 | 2023-06-19 |
| 初始金额 | ￥1,008 |
| 默认参数 | `n = 7` |
| 每日增长率 | 5% |
| 2023-06-21 档案值 | ￥1,111 |

在默认时间线中，2023-06-21 的金额为 `￥1,111`，这也是应用内“1111 档案”彩蛋的依据。

### 6.2 自定义配置的计算公式

设置自定义初始金额后，程序按以下模型计算：

```text
当日金额 = 初始金额 × 1.05 ^ 经过天数
```

其中：

```text
经过天数 = 当前日期 - 起始日期
```

日期早于起始日期时，经过天数按 0 处理，不会倒推为负金额。

### 6.3 舍入规则

- 所有金额为正数；
- 最终显示到整数元；
- 小数部分达到一半时向上取整；
- 不使用 `Int32` 或 `Int64` 保存完整金额；
- 核心大数计算使用 `BigInteger`，避免普通整数溢出。

### 6.4 99 位上限

程序最多显示 99 位金额。

超过上限后：

- 金额固定为 99 个 `9`；
- 弹窗标记“金额已达到99位上限”；
- 后续日期不会继续增加显示位数；
- BTC、外币和黄金换算仍以当前受限显示金额为基础。

### 6.5 数字格式

阿拉伯数字从右向左每三位添加一个英文逗号，例如：

```text
￥1,442,296,873,080,979,266,649,606,119 元
```

中文金额使用普通中文数字和单位，不使用财务大写字符，也不在末尾添加“整”。例如：

```text
人民币：四千四百四十四元
```

对于超大金额，会继续使用万、亿、兆、京、垓、秭、穰等更高单位。

### 6.6 修改起始日期或初始金额

1. 点击右上角“设置”。
2. 修改“起始日期”。
3. 在“初始金额（元）”中输入大于 0 的普通十进制数字。
4. 点击“保存”。
5. 主界面、趋势图、预测、迷你窗口和之后的每日快照会按新参数刷新。

不建议使用科学计数法或货币符号。请输入类似：

```text
1008
4444.50
```

## 7. 三条剧情路线

### 7.1 “认同”——档案调查路线

点击“认同”后打开自适应圆角弹窗。

典型流程：

1. 显示随机标题和第一阶段按钮；
2. 点击按钮后，弹窗立即根据下一阶段文字长度重新计算大小；
3. 展示剧情前言、欠款金额、BTC 估值、中文金额和复制按钮；
4. 点击当前剧情对应的按钮进入结尾；
5. 显示随机结语；
6. 点击“关闭”结束。

按钮文字不是固定的“对不起”，会根据本次随机剧情自动变化。

该路线会保存两类历史：

- 进入路线时的“认同”记录；
- 完成结尾时的“认同结尾”记录。

### 7.2 “非常认同”——共振与同盟路线

点击“非常认同”后进入多阶段文本弹窗。

- 每次进入会随机组合不同标题、过场和结尾；
- 按钮文字与当前剧情主题匹配；
- 中间阶段按钮显示“继续”；
- 最后阶段按钮显示“结束”；
- 设置了“自定义剧情文字”时，该文字会追加到剧情序列中。

### 7.3 “不认同”——警报与逃离路线

点击“不认同”后：

1. 主界面短暂切换到红色警告配色；
2. 打开警告弹窗；
3. 启动 10 秒逃离倒计时；
4. 弹窗在未启用“减少动画”时显示红色呼吸效果；
5. 点击“逃离”会随机选择一个逃离结果；
6. 如果倒计时归零，系统自动选择一条逃离路线；
7. 结果显示后，按钮变为“关闭”。

本次运行中，每第 4 次进入“不认同”会使用隐藏路线素材。

### 7.4 随机文案与重复选择

三条路线均使用组合式文案池。重复点击同一个按钮不代表会看到相同内容。

主页右侧路线进度使用历史选择记录计算，程序重启后仍保留；按钮卡片只显示本次运行的进入次数，不在按钮内部显示“1000”之类的组合总量。

## 8. 金额与 BTC 弹窗

“认同”路线的第二阶段提供完整金额信息。

### 8.1 人民币金额

显示格式包括：

- `￥` 前缀；
- 每三位英文逗号分隔；
- `元` 后缀；
- 普通中文数字写法；
- 99 位封顶提示。

金额数字进入页面时可播放滚动增长动画。启用“减少动画”后，弹窗淡入等动画会减少。

### 8.2 BTC 估值

进入金额详情后，程序才开始请求 BTC/CNY 行情。

显示格式：

```text
相当于：1,234.56789 BTC
```

BTC 固定精确到小数点后 5 位，并执行四舍五入。

行情获取过程中显示：

```text
相当于：等待获取实时比特币行情…
```

获取失败时显示网络提示，但人民币金额不受影响。

### 8.3 复制按钮

| 按钮 | 复制内容 |
|---|---|
| 复制人民币 | 带 `￥`、逗号和“元”的金额 |
| 复制 BTC | 带 5 位小数和 `BTC` 后缀的数值 |

BTC 按钮在行情尚未成功返回前保持不可用。

如果系统剪贴板正被其他程序占用，本次复制可能没有反应；稍后重试即可。

## 9. 数据面板

点击主界面右上角“数据”，或点击近七日图表、最近选择、成就卡片，即可打开数据面板。

数据面板包含三个标签页。

### 9.1 “概览”标签页

显示：

- 当前运行天数；
- 当前计算公式；
- 当前金额；
- 昨日金额；
- 七日前金额；
- 三十日前金额；
- 明日预测；
- 一周后预测；
- 一年后预测；
- 美元估值；
- 欧元估值；
- 日元估值；
- 港币估值；
- 黄金重量估值。

金额很长时，数据面板会根据最长一行自动增加窗口宽度；如果超过当前显示器工作区，则在允许范围内换行和增高。

### 9.2 “增长折线图”标签页

完整图表使用最近 30 天至今天共 31 个日期点。

由于金额可能跨越大量数量级，纵轴使用以 10 为底的对数值，标题会显示：

```text
欠款增长（对数刻度）
```

图表左右下角分别标注开始日期和结束日期。

### 9.3 “历史与成就”标签页

内容包括：

- 当前连续签到天数；
- 已解锁成就列表；
- 最近 100 条选择记录；
- 每条记录的时间、分支和剧情结果；
- “重新开始剧情”按钮。

### 9.4 “重新开始剧情”的影响

点击后会立即：

- 清空选择历史；
- 清空成就；
- 将连续签到显示重置为 1；
- 将主界面三条路线的本次计数归零；
- 将主页右侧三色路线进度归零；
- 刷新历史和成就页面。

不会清除：

- 起始日期和初始金额；
- 主题、字号和强调色；
- 自定义标题、问题和人物；
- 窗口位置；
- 已保存的每日金额快照。

该操作没有额外确认弹窗。如果需要保留历史，请先备份本地数据文件。

## 10. 设置页面

点击主界面右上角“设置”打开设置窗口。

### 10.1 字段说明

| 设置项 | 作用 | 范围或说明 |
|---|---|---|
| 起始日期 | 计算经过天数的第一天 | 日期早于它时按第 0 天计算 |
| 初始金额（元） | 自定义第 0 天金额 | 必须是大于 0 的普通十进制数 |
| 窗口标题 | 主窗口左上角标题 | 最长 80 字符 |

## 15. 联网行情与计算精度

### 15.1 IP 地区与自动分流

首次打开需要行情的页面时，程序会查询当前公网 IP 对应的两位国家或地区代码。结果在内存中缓存约 30 分钟：

- 检测到 `CN`：优先使用中国网络路径；
- 检测到其他代码：优先使用国际路径；
- IP 查询端点不可用：临时参考系统地区，并把缓存缩短为约 5 分钟；
- 无论选择哪条路径，首选行情失败后都会尝试另一组来源。

IP 地区判断只用于选择行情源，不会保存完整公网 IP。

### 15.2 BTC 行情

中国 IP 的 BTC/CNY 查询顺序：

1. 取得 MEXC 的 BTC/USDT 公开行情；
2. 取得中国银行美元“中行折算价”；
3. 将 BTC/USDT 与人民币兑美元折算价组合为 BTC/CNY 估值；
4. 中国路径失败后依次尝试 Coinbase 和 CoinGecko。

其他地区优先使用 Coinbase、CoinGecko，失败后再尝试 MEXC 与中国银行组合路径。如果本次会话中存在旧缓存，全部实时来源失败时可以继续显示旧缓存。

技术行为：

- 单次请求超时约 8 秒；
- 响应大小限制为 512 KiB；
- BTC 行情在内存中缓存约 1 分钟；
- BTC 最终显示 5 位小数；
- 超大人民币金额使用大整数除法，不先转换成浮点数。

### 15.3 外币行情

数据面板从 CNY 基准行情换算：

- USD 美元；
- EUR 欧元；
- JPY 日元；
- HKD 港币。

检测到中国 IP 时，程序优先读取中国银行的美元、欧元、日元、港币“中行折算价”，并从“每 100 外币对应人民币”换算成“每 1 元人民币对应外币”。其他地区优先使用 Coinbase 的 CNY 基准行情。首选失败时自动尝试另一来源。

外币显示 2 位小数，内存缓存约 5 分钟。

### 15.4 黄金重量

检测到中国 IP 时，黄金优先使用上海黄金交易所 Au99.99 行情，价格单位本身就是人民币元/克。其他地区优先使用 CoinGecko 的 PAX Gold（PAXG）人民币行情，并从每金衡盎司换算为每克。首选失败时自动尝试另一来源。

重量计算：

1. 用人民币欠款除以每克价格；
2. 再除以 1,000,000，把克换算成吨；
3. 显示 6 位小数和“吨”单位。

黄金行情失败时，外币可能仍可显示，黄金一项会显示“暂不可用”。

### 15.5 重要说明

所有行情换算均为展示用途：

- 不代表实际成交价；
- 不包含点差、手续费、税费和市场深度；
- BTC/USDT 按 1 USDT 约等于 1 USD 进行组合估值，不是直接 BTC/CNY 成交价；
- PAXG 或 Au99.99 行情均只是黄金估值参考；
- 不构成投资、借贷、会计或法律建议。

## 18. 故障排查

### 18.1 Setup 没有显示安装页面，只看到 UAC

原因可能是：

- UAC 窗口正在其他窗口后面；
- 用户尚未点击“是”；
- 用户点击了“否”，安装器因此没有启动；
- 正在运行静默测试参数，而不是普通双击 Setup。

处理方法：普通双击 `Setup.exe`，接受一次 UAC，等待中文向导出现。

### 18.2 明明安装了 .NET 8，Setup 仍提示下载

当前安装器会同时检查 x64 注册表视图和标准运行时目录。仍出现提示时，可在 PowerShell 执行：

```powershell
dotnet --list-runtimes
```

应能看到类似：

```text
Microsoft.WindowsDesktop.App 8.0.x [C:\Program Files\dotnet\shared\Microsoft.WindowsDesktop.App]
```

只有 `Microsoft.NETCore.App` 而没有 `Microsoft.WindowsDesktop.App 8.x` 时，仍需要 Desktop Runtime。

### 18.3 行情一直显示不可用

检查：

- 互联网连接；
- 系统日期和时间；
- 防火墙、DNS 或代理是否阻止 Cloudflare、Country.is、中国银行、上海黄金交易所、MEXC、Coinbase 或 CoinGecko；
- 是否在 8 秒超时前关闭了弹窗；
- 行情服务是否临时限流或维护。

人民币金额不依赖网络，可以继续使用。

### 18.4 BTC 复制按钮不可用

只有行情成功返回后，“复制 BTC”才会启用。等待文字变成具体 BTC 数值后再点击。

### 18.5 文字被裁切或窗口太小

建议依次尝试：

1. 最大化窗口；
2. 使用内容区滚动条；
3. 在设置中降低字号缩放；
4. 按 F11 使用全屏；
5. 检查 Windows 显示缩放是否极高；
6. 将窗口移动到分辨率更高的显示器。

弹窗会在进入下一段文案时立即重新计算尺寸，不会一直固定为第一阶段大小。

### 18.6 深色模式文字变了但背景不对

在设置中把主题从 `System` 改成明确的 `Dark` 或 `PureBlack`，然后保存。程序会同时刷新背景、卡片、文字和标题栏。

### 18.7 金额与预期不一致

核对：

- Windows 当前日期；
- 设置中的起始日期；
- 初始金额；
- 是否已经达到 99 位上限；
- 是否把自定义设置误认为默认 2023-06-19 时间线。

### 18.8 更新后仍显示旧标题或旧问题

这是配置保留行为。打开“设置”，把标题和问题手动改为当前默认值并保存。

### 18.9 重新开始剧情后哪些内容会丢失

会清除选择历史和成就，并重置路线进度。设置和每日快照保留。执行前可备份 `history.json`。

### 18.10 找不到桌面图标

桌面快捷方式默认是可选任务。可从开始菜单启动，或重新运行 Setup 并勾选创建桌面快捷方式。
