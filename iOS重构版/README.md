# 是否认同 iOS 重构版

本工程依据 Windows 安装包 `Installer/Output/Setup.exe`（1.1.0）对应的源码、Assets、配置与数据模型重构。

包含：

- 2023-06-19 固定锚点、初始金额 1008、每日 1.05 倍与 99 位安全上限；
- 人民币数字及中文写法；
- 三个剧情分支，每个分支至少 1,000 种组合；
- 动态圆角剧情页、历史选择、签到、成就与每日快照；
- 昨日/七日前/三十日前比较，明日/一周后/一年后预测；
- 30 日对数增长图；
- BTC、美元、欧元、日元、港币及黄金吨数换算；
- 中国线路优先与国际线路备用；
- 浅色、深色、纯黑主题、强调色、字号、高对比度和减少动画；
- TGLab 与“天国智造”版权信息；
- 与 Windows Setup 一致的应用图标。

生成目录中的 IPA 为未签名包，可交给签名工具处理；真机直接部署需要 Apple ID 开发签名。
